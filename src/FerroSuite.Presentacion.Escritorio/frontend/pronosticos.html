IA · red neuronal local (ONNX)

Pronóstico de demanda y reposición

Una red neuronal entrenada con PyTorch estima cuánto se venderá de cada producto en los próximos 7 días a partir de sus ventas de los últimos 28. Con el stock actual y el tiempo de entrega del proveedor, el programa sugiere qué pedir. Las sugerencias no crean ni aprueban órdenes: puedes usarlas para preparar una, que queda pendiente de aprobación.

"Red neuronal": consumo estimado por el modelo. "Regla de stock mínimo": respaldo cuando el producto no tiene historial suficiente o el modelo no está disponible (el motivo aparece en cada fila). El modelo actual fue entrenado con datos SINTÉTICOS: valida la integración, no reemplaza el criterio de quien compra.
